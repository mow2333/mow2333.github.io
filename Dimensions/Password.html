密码保护

密码保护

🔐 功能概述

维度创建时可设置密码保护，传送时需输入正确密码才能进入。适用于私人基地、团队专属维度、活动专用世界等场景。

🔧 设置密码

创建时设置

GUI 界面： 1. 勾选 "Enable Password" 2. 输入 4-16 位密码（字母、数字、下划线） 3. 点击创建

命令行：

/worldbridge create SecretBase default --password mySecret123

修改/移除密码

GUI：/worldbridge edit <dim> → 修改 Password 栏（留空 = 移除）

命令行（OP 专用）：

# 重置密码（清空，随后可在 GUI/传送时重新设置）
/worldbridge resetpassword <dim>

🔄 传送验证流程

sequenceDiagram
    Player->>Server: /worldbridge tp <dim>
    Server->>DimensionData: 检查 password 字段
    alt 密码为空
        Server->>Player: 直接传送
    else 密码非空
        Server->>Player: 发送 OpenPasswordScreenPacket
        Player->>Client: 打开密码输入界面
        Player->>Server: 输入密码 → VerifyPasswordPacket
        Server->>DimensionData: SHA-256 比对
        alt 密码正确
            Server->>Player: 传送进维度
        else 密码错误
            Server->>Player: 聊天栏提示 "Wrong password!"
        end
    end

🔑 密码规则

规则 详情
长度 4-16 字符
字符集 字母 (a-z, A-Z)、数字 (0-9)、下划线 _
存储 SHA-256 哈希存储，原文不落盘
传输 客户端→服务端 明文传输（局域网/本地服务器可接受），建议仅在受信网络使用

🔧 OP 管理命令

命令 权限 说明
/worldbridge resetpassword <dim> OP 2 清空密码，随后可重新设置

注意：无法通过命令直接“改密码”，只能先 resetpassword 清空，再通过 GUI/传送时重新设置。

🛡️ 安全建议

场景 建议
公共服务器 核心基地、资源维度、管理员专用维度必须设密码
私人服务器 可选，建议核心资源维度加锁
临时活动维度 活动结束后 /worldbridge delete 或改密码
密码泄露 立即 /worldbridge resetpassword <dim> 重置

❓ 常见问题

问题 解决
忘记密码 OP 执行 /worldbridge resetpassword <dim> 重置
密码正确但传送失败 检查维度是否存在、是否已加载、日志 latest.log 报错
想改密码 先 /worldbridge resetpassword <dim> 清空，再传送时重新设置
想取消密码保护 /worldbridge resetpassword <dim> 清空即可
