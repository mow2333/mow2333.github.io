维度参数详解

维度参数详解

创建维度时可配置的所有参数完整参考。

📋 参数总览表

参数 简写 类型 默认值 适用类型 说明
--name -n string 必填 所有 维度显示名称
--world-type -t enum 必填 所有 8 种世界类型之一
--biome -b resource_location - single_biome 固定生物群系
--seed -s long 随机 所有 世界种子
--difficulty -d enum normal 所有 peaceful/easy/normal/hard
--structures -st boolean true 所有 生成结构开关
--sea-level -sl int 63 除 deep_abyss 海平面 (-64~255)
--caves -c boolean true 除 flat 洞穴生成开关
--ore-veins -ov boolean true 除 flat 矿脉生成开关
--legacy-random -lr boolean false 所有 旧版随机种子兼容
--password -p string 无 所有 4-16 位密码
--difficulty-lock -dl boolean false 所有 锁定难度不可改

🔍 参数详解

--world-type / -t 世界类型

值 名称 生成器 备注
default 默认 NoiseBasedChunkGenerator 标准主世界
amplified 放大化 NoiseBasedChunkGenerator (amplified) 极限地形
flat 超平坦 FlatChunkGenerator 创造建筑
single_biome 单一群系 NoiseBasedChunkGenerator 需配合 --biome
caves 洞穴世界 NoiseBasedChunkGenerator (caves) 地下生存
aetherial_fields 星界之野 RuinedChunkGenerator(AETHERIAL_FIELDS) 核心维度
deep_abyss 幽邃深渊 NoiseBasedChunkGenerator 核心维度

核心维度（后 2 种）为模组原创，不可修改生物群系/生成器逻辑。

--biome / -b 生物群系

  • 仅 single_biome 类型必须填写
  • 格式：namespace:path，如 minecraft:meadow、minecraft:cherry_grove
  • 可用 /worldbridge create test single_biome -b minecraft: + Tab 补全查看

--seed / -s 种子

  • 64 位长整数，范围 -9223372036854775808 ~ 9223372036854775807
  • 留空 = 随机种子
  • 固定种子 = 地形可复现，便于备份/分享/重建

--difficulty / -d 难度

值 对应
peaceful 和平
easy 简单
normal 普通 (默认)
hard 困难

创建后可用 --difficulty-lock true 锁定，防止后续修改。

--sea-level / -sl 海平面

  • 范围：-64 ~ 255
  • 不适用于 deep_abyss（固定 -64）
  • aetherial_fields 实际海平面受 Y<100 虚空化影响

--caves / -c 与 --ore-veins / -ov

开关 作用 不适用类型
--caves 洞穴/峡谷生成 flat
--ore-veins 矿脉（铜/铁/金等大矿脉） flat

--legacy-random / -lr 旧版随机

  • true = 使用 1.17 前的随机种子算法（旧版地形兼容）
  • false = 现代随机（默认）
  • 主要用于复现旧版本地形或旧种子地图迁移

--password / -p 密码

  • 长度：4-16 字符
  • 支持字母、数字、符号
  • 设置后：传送、编辑、删除均需验证
  • 重置：/worldbridge resetpassword <pairId> (OP 2)

--difficulty-lock / -dl 难度锁定

  • true = 创建后不可通过 /difficulty 或 GUI 修改难度
  • false = 允许后续修改（默认）

📝 完整示例

# 标准生存世界
/worldbridge create Survival default -s 12345 -d normal -st true -sl 63

# 单一群系（樱花林），指定种子，困难模式
/worldbridge create Sakura single_biome -b minecraft:cherry_grove -s 987654321 -d hard

# 星界之野（浮空岛），关闭结构
/worldbridge create SkyIsles aetherial_fields -st false


# 幽邃深渊，锁定困难难度
/worldbridge create Deep deep_abyss -d hard -dl true

# 超平坦创造世界
/worldbridge create Build flat -dl true

# 洞穴世界，关闭矿脉
/worldbridge create Cavern caves -ov false

⚠️ 常见错误

报错 原因 解决
World type 'xxx' not found 类型拼写错误 检查拼写、下划线、大小写
Biome required for single_biome 单一群系未给 biome 加 -b minecraft:xxx
Password too short/long 密码长度不符 4-16 字符
Seed out of range 种子超出 long 范围 -9223372036854775808 ~ 9223372036854775807
Dimension 'xxx' not found tp 时维度不存在 先 /worldbridge list 确认 pairId
