安装与配置

安装与配置

📥 安装要求

项目 要求
Minecraft 1.19.4 / 1.20.1
Forge 1.19.4 → 45.2.0+ / 1.20.1 → 47.2.0+
Java 17+

📦 安装步骤

  1. 安装 Forge - 下载对应版本的 Forge Installer - 运行 java -jar forge-installer.jar --installClient / --installServer

  2. 放入模组 - 将 WorldBridge-<version>.jar 放入 .minecraft/mods/（客户端）或 server/mods/（服务端）

  3. 启动游戏 - 客户端：正常启动 Forge 配置文件 - 服务端：java -Xmx4G -jar forge-server.jar nogui

  4. 验证安装 - 进游戏后按 F3 确认 Forge 加载 - 聊天栏输入 /worldbridge list 应返回 No dimensions created yet.

⚙️ 配置文件

首次运行后，会在以下位置生成配置：

端 路径
客户端 .minecraft/config/worldbridge-client.toml
服务端 serverconfig/worldbridge-server.toml

主要可调项（服务端 worldbridge-server.toml）：

[dimension]
maxDimensionsPerPlayer = -1  # -1 无限制

[world_anchor]
baseTeleportRange = 5
overchargeTeleportRange = 9
baseBlessingRange = 3
overchargeBlessingRange = 5
baseBlessingAmplifier = 0
overchargeBlessingAmplifier = 1
overchargeDurationTicks = 1200
cooldownTicks = 0
chunkLoadEnabled = true

[feature]
voidShieldEnabled = true
voidShieldConsumeInInventory = true
starAnchorRecallEnabled = true

修改后执行 /worldbridge reload 或重启服务端生效。

🔧 常见问题

现象 原因 解决
进游戏崩溃 NoClassDefFoundError Forge 版本不匹配 对照版本表下载正确 Forge
/worldbridge 提示 Unknown command 模组未加载 检查 mods/ 目录、Forge 版本
创建维度卡死 种子冲突/反射失败 更换种子、检查日志 latest.log
传送后卡在虚空 安全落点扫描失败 更新到最新版、检查 TeleportHelper 日志

📁 目录结构参考

.minecraft/
├── mods/
│   └── WorldBridge-<ver>.jar
├── config/
│   └── worldbridge-client.toml
├── saves/
│   └── <world>/
│       └── serverconfig/
│           └── worldbridge-server.toml
└── logs/
    └── latest.log

提示：配置修改后推荐 /worldbridge reload 热重载，避免重启服务器。
