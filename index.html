🎮 快速上手 3 步

# 1. 安装 Forge (1.19.4 - 45.2.0+ / 1.20.1 - 47.2.0+)
# 2. 将 WorldBridge-x.x.x.jar 放入 mods/
# 3. 启动服务端/客户端 → 完成！

# 游戏内首次创建维度
/worldbridge create MyWorld default minecraft:plains 12345
# → 生成 PairID (如 a3f2) → 自动创建维度 → 返回 PairID

# 传送进去
/worldbridge tp MyWorld
# 或使用 PairID
/worldbridge tp a3f2b1c4
