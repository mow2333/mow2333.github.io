服务端配置

服务端配置

配置文件：worldbridge-server.toml (服务端 serverconfig/ 或 .minecraft/config/)

📋 配置项总览

分类 键 类型 默认值 说明
维度 maxDimensionsPerPlayer int -1 每玩家最多创建维度数，-1 无限制
世界之锚 baseTeleportRange int 5 红石传送半径 (正常)
overchargeTeleportRange int 9 红石传送半径 (过载)
baseBlessingRange int 3 祝福光环半径 (正常)
overchargeBlessingRange int 5 祝福光环半径 (过载)
baseBlessingAmplifier int 0 祝福等级 (正常，0=I)
overchargeBlessingAmplifier int 1 祝福等级 (过载，1=II)
overchargeDurationTicks int 1200 过载持续 (tick，1200=60s)
cooldownTicks int 0 传送冷却 (tick，0=无)
chunkLoadEnabled bool true 锚点强制加载 Chunk
功能开关 voidShieldEnabled bool true 虚空护盾开关
voidShieldConsumeInInventory bool true 虚空护盾消耗物品
starAnchorRecallEnabled bool true 星锚召回开关

📝 完整示例

# worldbridge-server.toml

[dimension]
maxDimensionsPerPlayer = -1

[world_anchor]
baseTeleportRange = 5
overchargeTeleportRange = 9
baseBlessingRange = 3
overchargeBlessingRange = 5
baseBlessingAmplifier = 0
overchargeBlessingAmplifier = 1
overchargeDurationTicks = 1200
cooldownTicks = 0
chunkLoadEnabled = true

[feature]
voidShieldEnabled = true
voidShieldConsumeInInventory = true
starAnchorRecallEnabled = true

🔧 生效方式

修改方式 生效方式
编辑文件后 执行 /worldbridge reload (OP 2)
重启服务端 自动重新加载

注意：客户端配置 worldbridge-client.toml 仅含渲染相关，不影响服务端逻辑。

🔧 常见调优

场景 建议值
多人生存服，防滥用维度 maxDimensionsPerPlayer = 3
硬核生存，限制传送 cooldownTicks = 1200 (60s)
PVP 服，关闭虚空护盾 voidShieldEnabled = false
红石自动化传送频繁 cooldownTicks = 200 (10s)
大型服务器，减少 Chunk 加载 chunkLoadEnabled = false
