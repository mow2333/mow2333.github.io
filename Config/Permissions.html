权限与上限

权限与上限

🔑 权限等级对照

命令 最低 OP 级别 说明
/worldbridge (无参数打开 GUI 创建) OP 2 创建维度 (GUI)
/worldbridge tp <dimension> [player] OP 2 传送
/worldbridge list OP 2 列出维度
/worldbridge edit <pairId> OP 2 编辑维度配置 (GUI)
/worldbridge rename <pairId> <name> OP 2 重命名
/worldbridge delete <pairId> OP 3 删除维度 (高危)
/worldbridge reload OP 2 热重载配置
/worldbridge resetpassword <pairId> OP 2 重置密码

OP 级别对应 server.properties 的 op-permission-level： - OP 2 = op-permission-level=2 (默认) - OP 3 = op-permission-level=3 (仅服主/最高管理)

📊 维度上限配置

配置文件 worldbridge-server.toml：

[dimension]
maxDimensionsPerPlayer = -1  # -1 = 无限制，0 = 禁止创建，>0 限制数量
值 效果
-1 无限制 (默认)
0 禁止所有玩家创建维度 (仅 OP 可通过命令创建)
N > 0 每个玩家最多创建 N 个维度，超限提示 Maximum dimensions reached

注意：OP 玩家不受此限制，始终可创建。

🔐 维度密码与权限

场景 权限要求
创建时设密码 OP 2 (创建权限)
传送时输密码 无需 OP，知密码即可
OP 强制重置密码 OP 2 (/worldbridge resetpassword <pairId>)
取消密码保护 同上 (重置为空)

密码以 SHA-256 哈希存储，原文不落盘。

🛡️ 维度删除保护

条件 行为
维度内有玩家 拒绝删除，提示 Cannot delete: players still inside
维度不存在 报错 Dimension not found
无权限 提示 Insufficient permission (需 OP 3)

删除前会二次确认：需再次输入 PairID 确认。

🛡️ 建议权限分配策略

角色 推荐 OP 级别 可执行命令
普通玩家 无 OP 仅传送 (知密码)、查看列表
普通管理员 OP 2 创建/传送/编辑/重命名/重置密码/重载配置
服主/最高管理 OP 3 全部权限 + 删除维度

建议：仅服主/最高信任管理设为 OP 3，普通管理给 OP 2。
