0.3.0 — 2026-08-06

✨ 新增

  • 自定义维度模板系统：JSON 模板 CRUD + GUI 管理，支持 biome_mix 多群系权重混合
  • 指令创建维度：/worldbridge world create <dimId> <typeAndJson>，支持内联 JSON 全参数覆盖，8 种内建类型 + 自定义模板
  • 红链无线红石系统：5 种方块（发射器/接收器/按钮/拉杆/压力板/以太触发器）+ 扳手配对，跨维度零延迟信号传输
  • 跨维度漏斗：INPUT/OUTPUT/BOTH 三模式，27 格缓冲 + 9 格过滤器，扳手两步配对，自动区块保活
  • 玩家可见红字错误提示：全链路异常反馈到聊天框

🔧 修复 (1.19.4)

  • 坐标要求规则扩大：任何 world_bridge: 命名空间维度传送均需坐标，原版维度间不需
  • biome_mix 群系键名修正：biome_name → biome，修复全变平原的 Bug
  • 跨维漏斗 pairId 不匹配/相邻箱子推送失败 兜底修复
  • 日志精简：移除高频调试日志，消除启动器崩溃隐患

0.2.3b — 2026-07-14

🔐 密码功能完全实现

  • 翻译键全覆盖：8 个密码相关 key (中英双语)
