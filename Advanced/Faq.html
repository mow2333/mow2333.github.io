常见问题 (FAQ)

常见问题 (FAQ)

🛠️ 安装与运行

Q: 必须客户端也装模组吗？

A: 必须。WorldBridge 是双端模组，客户端未装会导致：GUI 打不开、物品显示错误、成就不显示、动态光源失效、传送界面报错。

Q: 支持哪些 Forge 版本？

Minecraft Forge 推荐版本
1.19.4 45.2.0+
1.20.1 47.2.0+

Q: 能不能只装服务端？

A: 不能。客户端缺少模组会导致：GUI 打不开、物品显示错误、成就不显示、动态光源失效、传送界面报错。

🌍 维度创建与管理

Q: 为什么 /worldbridge create 报错 "Unknown command"?

A: 模组只注册了 worldbridge，没有 wb 别名。请用完整命令 /worldbridge create ...。

Q: 为什么 /worldbridge tp MyWorld 提示 "Invalid dimension"?

A: tp 接受的是 完整 ResourceLocation，不是维度名或 PairID。
正确用法：

/worldbridge tp world_bridge:a3f2b1c4
# 或
/worldbridge tp minecraft:the_nether

用 /worldbridge list 查看 PairID，拼成 world_bridge:<pairId>。

Q: 创建维度后传送失败 / 卡在虚空？

A: 常见原因： - 安全落点扫描超时 → 尝试指定种子 /worldbridge create ... -s 12345 - 目标维度未加载 → 先 /worldbridge list 确认状态，或先 /worldbridge tp 触发加载 - 日志 latest.log 搜 TeleportHelper 看报错堆栈

Q: 密码忘了怎么办？

A: OP 执行 /worldbridge resetpassword <pairId> 清空密码，随后传送时重新设置。

Q: 能不能修改已创建维度的类型/种子/群系？

A: 不能。创建后 类型、种子、群系、PairID 全部锁定，不可修改。

🏆 成就系统

Q: 成就解锁了但 Toast 不弹出？

A: 已知 1.20.1 下 SimpleCriterionTrigger 内部 listener map 可能为空导致静默失败。模组已在 ModTrigger.trigger() 中调用 awardDirectly() 兜底，极少数边缘情况仍可能漏触发。

Q: 进度标题显示 "???" 是 Bug 吗？

A: 不是。enter_chaos_abyssos 成就标题刻意设为 "???"，配合诗化描述隐晦暗示某个未知维度的名字。

⚙️ 配置与权限

Q: 修改 worldbridge-server.toml 后不生效？

A: 修改后需执行 /worldbridge reload (OP 2) 或重启服务端。

Q: 普通玩家能不能创建维度？

A: 默认 maxDimensionsPerPlayer = -1 (无限制)。改为 0 可禁止普通玩家创建，仅 OP 可通过命令创建。

Q: 怎么禁止普通玩家传送？

A: 传送命令需要 OP 2。普通玩家无 OP 无法使用 /worldbridge tp。若需允许普通玩家传送，需插件/权限模组配合。

Q: 怎么给普通管理员 OP 2 但禁止删除维度？

A: 删除维度需要 OP 3。给普通管理 OP 2，仅服主/最高信任给 OP 3。

📦 其它

Q: 能不能把模组加到模组包里发布？

A: 可以，遵循 MIT 许可证即可。

Q: 有没有 Fabric / NeoForge 版本？

A: 目前仅 Forge。其它加载器暂无计划。

Q: 能不能跟 XXX 模组兼容？

A: 只要不修改同一维度生成/传送逻辑，通常兼容。冲突请提 Issue 提供日志。

Q: 怎么提交 Bug / 建议？

A: GitHub Issues → 选择模板 → 填版本、日志、复现步骤。
