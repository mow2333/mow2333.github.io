📋 面板元素详解

区域 内容 可编辑
标题栏 维度名称、PairID ✅ 点击 ✏ 重命名
过载状态 当前状态 + 倒计时进度条 🚫 只读
范围/等级 传送/祝福范围、等级 (普通/过载) 🚫 只读 (配置文件控制)
区块加载 开启/关闭状态 🚫 只读 (配置文件控制)
密码保护 已启用/未启用 🚫 只读 (GUI/命令修改)
底部按钮 重命名、修改密码、关闭 ✅ 可点击

🔧 操作说明

操作 方法 权限
重命名 点击 ✏ → 输入新名 → 确认 OP 2
修改密码 点击 🔑 → 输入新密码/留空清除 → 确认 OP 2
修改配置 编辑 worldbridge-server.toml → /worldbridge reload OP 2 (服主)

🔧 过载机制

操作 效果 消耗
右键星锚奇点 → 点击世界之锚 进入过载 60 秒 1 个星锚奇点
过载结束 自动恢复正常范围/等级 —

过载期间增强： | 属性 | 正常 | 过载 | |------|------|------| | 传送范围 | 5 格 | 9 格 | | 祝福范围 | 3 格 | 5 格 | | 祝福等级 | 再生 I + 抗性 I | 再生 II + 抗性 II | | 粒子效果 | 无 | ENCHANT + END_ROD 旋转环 |

🔑 密码保护

场景 行为
传送进密码维度 弹出密码输入界面 → 正确 → 传送；错误 → 提示错误
GUI 查看 显示“已加密”，不显示明文
OP 重置 /worldbridge resetpassword <pairId> 清空密码
