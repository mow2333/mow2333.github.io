自定义维度数据包

自定义维度数据包

通过数据包扩展/覆盖 WorldBridge 维度类型、生成器参数、结构集合等。

📁 数据包结构

my-worldbridge-datapack/
├── pack.mcmeta
└── data/
    └── world_bridge/
        ├── dimensions/
        │   ├── my_custom_dimension.json
        │   └── another_dimension.json
        ├── worldgen/
        │   ├── noise_settings/
        │   │   └── my_custom_noise.json
        │   ├── biome/
        │   │   └── my_biome_source.json
        └── tags/
            └── worldgen/
                └── biome/
                    └── has_custom_structure.json

📝 维度定义文件

基础格式 (data/world_bridge/dimensions/my_dim.json)

{
  "type": "world_bridge:deep_abyss",
  "name": "My Deep",
  "seed": 123456789,
  "difficulty": "normal",
  "structures": true,
  "generation_config": {
    "sea_level": 63,
    "caves": true,
    "ore_veins": true,
    "legacy_random": false
  },
  "password": "",
  "biome": "minecraft:plains"
}

字段说明

字段 必填 类型 说明
type ✅ string 8 种世界类型之一
name ✅ string 维度显示名称
seed 否 long 留空随机
difficulty 否 string peaceful/easy/normal/hard
structures 否 bool 是否生成结构
generation_config 否 object 见下表
password 否 string 4-16 字符，留空无密码
biome 视类型 string single_biome 必填

generation_config 详解

键 类型 默认 说明
sea_level int 63 海平面 (Y)
caves bool true 生成洞穴
ore_veins bool true 生成矿脉
legacy_random bool false 旧版随机

🌌 自定义世界类型 (进阶)

需注册自定义 ChunkGenerator / BiomeSource / NoiseSettings，仅供高级用户。

1. 注册自定义 ChunkGenerator

// ModChunkGenerators.java
public static final DeferredRegister<ChunkGenerator> CHUNK_GENERATORS =
    DeferredRegister.create(Registries.CHUNK_GENERATOR, WorldBridge.MODID);

public static final RegistryObject<ChunkGenerator> MY_CUSTOM = CHUNK_GENERATORS.register(
    "my_custom",
    () -> new MyCustomChunkGenerator(/* 参数 */)
);

2. 数据包中引用

{
  "type": "world_bridge:my_custom",
  "name": "My Custom World",
  "custom_generator_config": {
    "my_param": 42
  }
}

🔧 常用数据包模板

1. 简单自定义维度（基于默认世界）

{
  "type": "default",
  "name": "My Survival",
  "seed": 12345,
  "difficulty": "normal",
  "generation_config": {
    "sea_level": 63,
    "caves": true,
    "ore_veins": true
  }
}

2. 星界之野变体（更高浮岛）

{
  "type": "aetherial_fields",
  "name": "High Islands",
  "seed": 999999,
  "generation_config": {
    "sea_level": 100,
    "caves": true
  }
}

3. 幽邃深渊变体（更深）

{
  "type": "deep_abyss",
  "name": "Deeper Dark",
  "generation_config": {
    "sea_level": -64
  }
}

📦 安装方式

  1. 将数据包文件夹放入服务端 world/datapacks/
  2. 执行 /reload 或重启服务端
  3. 创建维度时选择对应类型即可
