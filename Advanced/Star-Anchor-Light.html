星锚动态光源

星锚动态光源

🎯 问题背景

原版动态光源实现分两层，星锚奇点手持/掉落/展示发光时，两层都需修正：

层级 原版实现 影响范围 问题
LevelRenderer LevelRenderer.getLightColor() 手持物品覆盖层、粒子、方块破坏动画 仅拦截此处，实体渲染不受影响
EntityRenderer EntityRenderer.getPackedLightCoords() → BlockAndTintGetter.getBrightness() 实体渲染（掉落物、生物、物品展示） 完全不走 LevelRenderer.getLightColor

结论：必须同时 Hook 两层才能让星锚奇点在所有场景下发光。

🔧 实现方案

1. LevelRenderer 层

@Mixin(LevelRenderer.class)
public class ClientLevelMixin {
    @Redirect(
        method = "getLightColor",
        at = @At(value = "INVOKE", target = "Lnet/minecraft/client/renderer/LightTexture;getLightColor(Lnet/minecraft/core/BlockPos;)I")
    )
    private int boostLight(LightTexture instance, BlockPos pos) {
        int original = instance.getLightColor(pos);
        return Math.max(original, StarAnchorLightManager.getBoostedLightLevel(pos));
    }
}
  • 拦截 LightTexture.getLightColor(BlockPos)
  • 取 max(original, boosted) → 原版光源不被覆盖，星锚光源叠加

2. EntityRenderer 层

@Mixin(EntityRenderer.class)
public class EntityRendererMixin {
    @Redirect(
        method = "*",
        at = @At(
            value = "INVOKE",
            target = "Lnet/minecraft/world/level/BlockAndTintGetter;getBrightness(Lnet/minecraft/world/level/light/LightLayer;Lnet/minecraft/core/BlockPos;)I"
        )
    )
    private int redirectBrightness(BlockAndTintGetter getter, LightLayer layer, BlockPos pos) {
        int original = getter.getBrightness(layer, pos);
        if (layer == LightLayer.BLOCK) {
            return Math.max(original, StarAnchorLightManager.getBoostedLightLevel(pos));
        }
        return original;
    }
}
  • @Redirect(method = "*") 拦截所有方法中对 BlockAndTintGetter.getBrightness 的调用
  • 仅拦截 BLOCK 层，SKY 层保持原版
  • 同样取 max(original, boosted)

⚡ 关键技术点

点 说明
返回类型 int 1.20.1 getBrightness 返回 int (打包光照)，非 float，字节码 ireturn
LightLayer 位置 Mojmap 中为顶级类 net.minecraft.world.level.LightLayer，非 LightEngine 内部类
Mixins 映射 重映射后方法签名：getBrightness(LLightLayer;LBlockPos;)I → m_45517_
并发安全 StarAnchorLightManager.dirtyChunks 使用 CopyOnWriteArraySet 避免 CME
日志节流 移除所有 logThrottled 与计数器，消除启动器崩溃隐患

📦 StarAnchorLightManager 核心逻辑

public class StarAnchorLightManager {
    private static final CopyOnWriteArraySet<Long> dirtyChunks = new CopyOnWriteArraySet<>();
    private static final Map<Long, Integer> chunkLightCache = new ConcurrentHashMap<>();

    public static void markDirty(ChunkAccess chunk) {
        dirtyChunks.add(chunk.getPos().toLong());
    }

    public static int getBoostedLightLevel(BlockPos pos) {
        long chunkKey = ChunkPos.asLong(pos.getX() >> 4, pos.getZ() >> 4);
        return chunkLightCache.getOrDefault(chunkKey, 0);
    }

    public static void recalculate() {
        // 每 tick 重算脏区块光照
        for (long chunkKey : dirtyChunks) {
            // 扫描区块内星锚奇点，计算光照等级
        }
        dirtyChunks.clear();
    }
}
