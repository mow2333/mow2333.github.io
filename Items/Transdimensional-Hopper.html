跨维度漏斗

跨维度漏斗

版本：0.2.0
跨维度物品传输系统，支持 INPUT/OUTPUT/BOTH 三种模式，配对使用红链扳手。

概述

跨维度漏斗允许物品在不同维度之间自动传输。它将物品从源维度的容器中拉取，跨维度传送到目标维度的容器中。支持三种工作模式，可灵活配置上下游。

合成

配方：末影箱 ×4 + 漏斗 ×1 + 星锚奇点 ×3

E E E
E H E
S S S
  • E = 末影箱
  • H = 漏斗
  • S = 星锚奇点
  • 产出：1 个跨维度漏斗

工作模式

模式 方块颜色 行为
INPUT 蓝色 从周围容器拉取物品 → 内部缓冲 → 跨维传送
OUTPUT 橙色 接收配对端传送的物品 → 缓冲 → 推送到周围容器
BOTH 紫色 拉取 + 推送 + 跨维传送（双向）

模式通过 GUI 切换，方块纹理随模式变化。

配对

跨维度漏斗使用红链扳手进行配对，无需独立绑定工具。

配对步骤

  1. 手持红链扳手右键点击源端漏斗 → 聊天提示"已选择源漏斗"
  2. 前往目标维度，右键点击目标端漏斗 → 自动配对： - 生成唯一 pairId - 双向写入坐标和维度 - 源端自动设为 INPUT，目标端自动设为 OUTPUT - 播放配对音效

解绑

  • 再次用扳手点击已配对的对方 → 解除配对
  • 或在 GUI 中点击解绑按钮

物品传输

INPUT 模式

  1. 每 tick 扫描周围 3×3×3 范围的容器
  2. 发现可提取物品 → 拉取到内部缓冲区
  3. 每 10 tick 尝试向配对 OUTPUT 跨维传送（速率受配置限制）
  4. 传送成功 → 两端产生 END_ROD 粒子

OUTPUT 模式

  1. 接收配对 INPUT 传送来的物品 → 存入内部缓冲区
  2. 每 tick 扫描周围容器 → 将缓冲物品推送出去
  3. 支持过滤器白名单（仅推送指定物品）

红石触发

  • 红石信号高电平时 → 立即触发一次 tryTransfer()
  • 可配合比较器控制传送速率

比较器输出

  • redstoneSignal = filledSlots × 15 ÷ 27
  • 缓冲区越满，信号越强

交互

  • 模式按钮：点击循环切换 INPUT → OUTPUT → BOTH → INPUT
  • 频道码：编辑后点"设置"保存
  • 缓冲槽：左键取/放，Shift 快速移动
  • 过滤器：放入物品即加入白名单（空 = 所有物品允许）
  • 统计面板：显示累计传送数、吞吐率、最近 5 条记录
  • 玩家背包：可交互，支持 Q 键丢弃

指令

/worldbridge transhopper

子命令 参数 描述
list — 列出所有已加载的跨维度漏斗（按维度分组）
give <player> [count] 玩家名、数量 给予指定玩家跨维度漏斗
pair <srcDim> <srcPos> <tgtDim> <tgtPos> 4 组坐标 强制配对两个漏斗
unbind <dim> <pos> 维度、坐标 解绑指定位置的漏斗
reload — 热重载配置文件

坐标格式

<pos> := <dimensionId> <x> <y> <z>
例: world_bridge:cmd_abc 100 64 -200

服务端配置

在 worldbridge-server.toml 的 [transhopper] 段：

[transhopper]
enabled = true        # 总开关
max_rate = 64         # 最大传输速率（项/秒/方块），0=无限
scan_range = 4        # 主动扫描半径（方块）

技术细节

区块保活

跨维度漏斗通过 PORTAL 类型的 RegionTicket 保持自身和目标维度的区块加载：

  • 自身：每 10 tick 刷新 ticket（TTL 300 ticks）
  • 目标：已配对时自动为目标端也添加 ticket
  • 推送预加载：OUTPUT 推送扫描前，预加载 3×3 chunk 范围的所有未加载区块

维度自动加载

当目标维度未加载时，系统自动通过 DimensionDataManager 读取数据并重建维度。即使存档中的 pairId 与维度键不匹配，也会尝试回退到维度路径名查找。

Forge 兼容

由于 Forge 的 BlockEntityTicker 不 tick 未激活维度的 BE，系统通过 EventHandler.onServerTick() 手动遍历所有活跃的跨维度漏斗并调用其 tick()。

常见问题

Q: 物品传输很慢？
A: 检查 max_rate 配置项（默认 64 项/秒）。如果目标端缓冲区满，传输会暂停直到有空间。

Q: OUTPUT 端不推送物品到箱子？
A: 可能原因：箱子在未加载的区块中。系统有自动预加载机制，但如果箱子距离过远（> scan_range），请调整 scan_range。

Q: 找不到配对端？
A: 使用命令 /worldbridge transhopper list 查看所有已加载漏斗。确认两端维度都已加载且配对信息正确。
