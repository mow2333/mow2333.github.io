世界之锚

世界之锚

📦 基础信息

属性 值
注册名 world_bridge:world_anchor
最大堆叠 1
稀有度 普通
硬度 50.0
抗爆炸 1200.0
最佳工具 镐 (等级 3+)

⚙️ 核心功能

功能 触发 说明
跨维传送 右键 / 红石信号 传送到绑定的配对锚点 (跨维度)
红石触发 信号强度 > 0 范围内实体传送到绑定锚点
Chunk 常加载 放置后自动 所在 Chunk 强制加载，移除后移除
祝福光环 玩家进入范围 范围内玩家每 4 秒获得再生 + 抗性
过载模式 星锚奇点右键 60 秒：范围翻倍、效果强度 II
Chunk 常加载 放置后自动 所在 Chunk 强制加载，移除后移除

🎮 交互方式

动作 操作 说明
打开控制面板 右键方块 打开 GUI
红石触发 红石信号 > 0 范围内实体传送到配对锚点
过载充能 手持星锚奇点右键方块 消耗 1 个星锚奇点，过载 60 秒
重命名 GUI 点击 ✏ / 命令 显示在面板、传送提示、Tab 补全

📋 控制面板

打开 GUI 显示：

字段 说明
PairID 8 位十六进制，唯一标识
名称 自定义名，显示在传送提示、Tab 补全
状态 LOADED / UNLOADED / OVERCHARGED
过载剩余 剩余秒数 (过载时)
冷却剩余 冷却倒计时
配对锚点 显示配对锚点的 PairID、名称、坐标、维度
传送范围 当前生效范围 (过载时翻倍)
祝福范围/等级 当前生效范围与等级
操作按钮 传送、过载、重命名、设置密码

🔗 配对机制

规则 说明
配对 放置两个锚点 → 右键第一个 → 右键第二个 → 自动配对
唯一性 一个锚点只能与一个锚点配对
跨维度 支持跨维度配对与传送
去重 同维度 + 同坐标 = 复用已有锚点

⚡ 过载模式

触发 手持星锚奇点右键世界之锚
消耗 1 个星锚奇点
持续 60 秒 (1200 tick)
效果 传送范围 ×2、祝福范围 ×2、祝福等级 II
视觉 旋转 ENCHANT / END_ROD 粒子环

🛡️ 黑名单（不可传送方块）

方块 理由
基岩 防止传送到基岩层卡死
末地传送门 防止传送进传送门实体
末地传送门框架 同上

🎨 自定义名称

# 命令行
/worldbridge rename <pairId> "My Base"

# GUI
/worldbridge edit <pairId> → 点击 ✏ 重命名 → 输入新名
  • 显示在：控制面板标题、传送提示、Tab 补全提示
  • PairID 不变，锚点绑定不受影响

💎 合成配方

下界合金锭  紫珀块  下界合金锭
紫珀块      星锚奇点  紫珀块
下界合金锭  紫珀块  下界合金锭

🛡️ 红石触发细节

信号强度 行为
0 无反应
1-15 触发传送，范围内所有实体传送到配对锚点

可配合红石钟、观察者、日光传感器做自动传送装置。
