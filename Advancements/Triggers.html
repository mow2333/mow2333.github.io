触发器详解

WorldBridge 共注册 13 个自定义 Criterion Trigger，配合 11 个 Advancement 使用。

📋 触发器列表

enter_chaos_abyssos ModTrigger 首次进入未知领域 —
enter_aetherial_fields ModTrigger 首次进入星界之野 —
enter_deep_abyss ModTrigger 首次进入幽邃深渊 —
structure_any ModTrigger 发现任意天空结构 structureType (string)
structure_ship ModTrigger 发现末地船 —
structure_fortress ModTrigger 发现要塞 —
structure_bastion ModTrigger 发现堡垒遗迹 —
structure_ancient ModTrigger 发现古代城市 —

deep_reached ModTrigger 深渊 Y≤-32 y (int)
high_reached ModTrigger 星界 Y≥200 y (int)
deepest_reached ModTrigger 最深处 Y=-64 —
dimension_death ModTrigger 在模组维度死亡 dimension (string)

🔧 技术实现

ModTrigger 基类

public abstract class ModTrigger<T extends ModTrigger.Instance> extends SimpleCriterionTrigger<T> {
    @Override
    public void trigger(ServerPlayer player, T instance) {
        super.trigger(player, instance);
        // 兜底：直接授予进度，防止 Toast 不显示
        awardDirectly(player, instance);
    }

    protected void awardDirectly(ServerPlayer player, T instance) {
        // 硬编码映射：trigger path → advancement + criterion
        // 直接调用 PlayerAdvancements.award()
    }
}

关键点：SimpleCriterionTrigger.trigger() 在 1.20.1 中 listener map 可能为空，导致静默失败。ModTrigger 在 super.trigger() 后额外调用 awardDirectly() 直接授予 criterion，确保进度必触发。

// ModCriteria.java

public static final ModTrigger ENTER_AETHERIAL_FIELDS = register("enter_aetherial_fields", EmptyTriggerInstance::new);

// FMLCommonSetupEvent#enqueueWork
CriteriaTriggers.register(ModCriteria.ENTER_CHAOS_ABYSSOS);
// 必须在 enqueueWork 中注册，非线程安全

📍 触发位置

触发器 触发位置
dimension_created ModNetworking.handleCreateDimension() → TeleportHelper.fireDimensionTriggers()
enter_* TeleportHelper.teleportEntity() 中根据生成器类型判断
structure_* RuinedChunkGenerator 结构放置后记录到静态 Map → EventHandler tick 检测玩家附近 3x3 区块
deep_reached / high_reached EventHandler.onPlayerTick() 每 20 tick 检查 Y 坐标
deepest_reached 同上，额外检查 Y=-64
dimension_death EventHandler.onPlayerDeath() 判断维度类型
